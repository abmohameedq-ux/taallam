# تعلّم مع الهيثم — الإصدار التجريبي 1.0

تطبيق ويب عربي RTL للأطفال، يعمل على Node.js دون مكتبات خارجية، ويمكن نشره على Railway.

## الموجود في هذه النسخة
- واجهة عربية متجاوبة مع الهاتف والكمبيوتر.
- ثلاثة نماذج دروس تجريبية: جمع التفاحات، حرف الألف، واحتياجات النبات.
- أسئلة اختيار من متعدد وتغذية راجعة فورية.
- نطق الشرح عبر ميزة تحويل النص إلى كلام في المتصفح، إذا كان الجهاز يدعم العربية.
- تجربة استماع تجريبية عبر Web Speech API في المتصفحات الداعمة.
- ملف طفل اختياري (اسم وصورة وعمر اختياري) وتقدّم محفوظ محليًا في المتصفح.

## تشغيل محلي
تحتاج Node.js 18 أو أحدث:

```bash
npm start
```

ثم افتح `http://localhost:3000`.

## النشر على Railway
1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. أنشئ مشروعًا جديدًا في Railway واربط المستودع.
3. أمر التشغيل: `npm start` (محدد في package.json).
4. لا يحتاج هذا النموذج إلى متغيرات بيئة إضافية. Railway يمرّر PORT تلقائيًا.
5. استخدم نطاق Railway مع HTTPS لتجربة الميكروفون، مع العلم أن دعم الصوت يختلف بين المتصفحات والأجهزة.

## حدود مهمة — قبل استخدامه مع أطفال حقيقيين
هذا **نموذج أولي** وليس منتجًا تعليميًا مكتملًا أو خدمة ذكاء اصطناعي متصلة. لا يوجد اتصال بنموذج لغوي، ولا حسابات خادم، ولا مزامنة بين الأجهزة، ولا لوحة ولي أمر، ولا منهج يمني موثّق، ولا ضمان لجودة التعرّف على اللهجة اليمنية. الردود الصوتية الحالية محدودة بقواعد بسيطة، والدروس الثلاثة عينات أولية وليست بديلًا عن المنهج الدراسي.

الملفات الشخصية والتقدم محفوظان في `localStorage` على الجهاز نفسه ويمكن حذفهما بمسح بيانات الموقع. لا تدخل معلومات حساسة عن الطفل. قبل إطلاق عام، يلزم إضافة موافقة ولي الأمر، وسياسة خصوصية واضحة، وضوابط سلامة للمحتوى، واختبارات مع أولياء أمور ومعلمين، ثم ربط آمن بخدمة ذكاء اصطناعي وتخزين مناسب عند الحاجة.

## الملفات
- `server.js`: خادم HTTP بسيط.
- `public/index.html`: بنية الواجهة.
- `public/styles.css`: التصميم المتجاوب.
- `public/app.js`: منطق الدروس والصوت والتقدم.
